This is the real dispatch_block()/MsgReceive() path — every `cat` here is a genuine
open()+read() from the client, turned into a MsgSend by libc, routed by the QNX
Neutrino microkernel to vehicle_resmgrd, answered via MsgReply. Nothing here goes
through the HOST=1 Linux stub (whose dispatch_block() just returns NULL immediately
and never exercises this code path at all).
